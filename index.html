SecuritySecurity

Security-first builds for fintech, crypto and AI-assisted software.

Most of what I build now touches money, wallets, agents or code an AI helped write. Each fails in its own way, and the design has to account for that before the first screen is drawn.

01

Wallets and signing

A person approves every signature. The app shows what a transaction does in plain words before it is signed, holds no keys and sends nothing on its own. In RobotFac3 the wallet sends; the browser only prepares.

02

Agents with a payment policy

An agent that can pay gets a strict grammar for payment sentences, a leak check and an injection detector. Anything outside the grammar stops and asks a person.

03

AI that asks

Quote On: with no rate on file, the AI requests one. Rules like that are designed into the flow, written down and tested like any other feature.

04

Written with AI, then reviewed

AI-written code ships after an adversarial review and regression tests. RobotFac3 v0.2: 35 findings from one review, all fixed, each covered by a test.

05

Fewer strangers in the code

Hand-written Solana layer, standard-library relay, no npm, no CDN, no web fonts. The relay allow-lists files and RPC methods, refuses wrong Host headers and cross-origin posts, and never reuses a connection.

06

Client baseline

Every client build starts the same way: MFA and domain lock, SPF, DKIM and DMARC, per-client isolation, backups and a written incident plan. The client owns the domain, the data and the code.

07

Payments, identity and compliance

Card and identity data go straight to the processor or the KYC provider and never pass through code we wrote. A certified security engineer is on every build. The proposal names the standards that apply to you, and the build is reviewed against them before launch.

08

Your idea stays off the model

A brand is built to surprise, and what a model has seen it can reproduce. So unreleased work, client files and data never go into one. Ideation draws on every model worth using, on prompts that name nothing, because each thinks differently and that range is part of the craft. Client material reaches only models designed for data sovereignty. Where each model sits.
